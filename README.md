## 先把“原生”两个字讲清楚

原生 IP 的判定标准只有一条：**IP 段的注册归属地和机房物理位置一致**。亚太的 IP 段由 APNIC 分配，日本机房拿到的就该是日本本土运营商名下的段，whois 查出来 country 一栏写着 JP，IP 属性库里也不会冒出 Relay、Proxy、Data Center 这类标注。

广播 IP 则相反。IP 段注册在别国，通过 BGP 广播“借”到日本机房用。查 whois，注册地可能是美国或香港，服务器却在东京。身份证和住址对不上，风控系统第一眼就会警觉。

自己动手核验只要三步：

1. 拿到 IP 后跑 whois，看 country 和 netname 是不是日本本土运营商。
2. 用 IP 属性检测工具看有没有被标成 hosting / IDC / proxy。
3. 查 scamalytics 之类的欺诈分，分数越高越像“有前科”的段。

### 原生机房 IP 不等于住宅 IP

这是全网最容易混在一起讲的一件事，也是选错套餐的主要原因。

“原生”只说明登记地一致，不说明这个 IP 的属性是家庭宽带。机房 IP 的 ASN 归属数据中心，哪怕它真的是日本注册、日本落地、whois 干干净净，平台照样能从 ASN 类型判断出“这是台服务器”。住宅 IP 的 ASN 归属 ISP，属性标注为 residential，平台看到的是“某个日本家庭的路由器”。
